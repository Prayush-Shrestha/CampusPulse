# CampusPulse — Campus Event & Club Management System

A modern Next.js dashboard concept for managing university events, student clubs, registrations, attendance, announcements and reports.


## Technology stack
- Next.js 15 App Router
- React 19
- TypeScript
- Tailwind CSS 4 (base setup)
- Lucide React icons

## Getting started
1. Install Node.js 20 or newer.
2. Extract this ZIP and open the folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Visit http://localhost:3000.

## Pages
- `/` Overview dashboard
- `/events` Event management
- `/clubs` Club management
- `/registrations` Registration management
- `/attendance` Attendance tracking
- `/announcements` Campus announcements
- `/reports` Reports and analytics
- `/settings` Workspace settings

## Current status
This is an initial UI scaffold with dashboard styling, sidebar navigation, responsive layout, demo records, and module pages. It does not yet include database persistence, authentication, live event CRUD, or production-ready permissions. Those can be added as the next development phase.
